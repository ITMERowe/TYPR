# Security policy

## Reporting a vulnerability

Please report security issues privately to the repository owner rather than opening a public issue containing exploit details.

## Project security principles

TYPR is intentionally designed without:

- privileged services
- persistence mechanisms
- telemetry
- remote control
- credential collection
- hidden payloads
- automatic network communication

Security-related changes should preserve these properties unless the repository maintainers explicitly document a different design decision.

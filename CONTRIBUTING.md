# Contributing

Contributions are welcome.

## Development

1. Install the .NET 8 SDK on Windows.
2. Fork and clone the repository.
3. Create a feature branch.
4. Make your changes.
5. Verify the project builds with:

```powershell
dotnet build -c Release
```

6. Open a pull request describing the change and how it was tested.

Please keep the project focused on transparent keyboard-input automation. Features that introduce hidden persistence, privilege escalation, credential collection, covert networking, or similar behavior are outside the scope of this project.
